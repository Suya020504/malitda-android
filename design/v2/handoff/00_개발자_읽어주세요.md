# 말잇다 개발 전달 추가자료

최종 42화면 PNG와 함께 사용하는 와이어프레임·에셋·폰트 묶음입니다.

## 자료 적용 기준

- 화면의 색상·서체·레이아웃은 별도로 전달한 `말잇다_v2_전체42화면.zip`의 PNG를 기준으로 합니다.
- `01_documents/말잇다_와이어프레임_목업42쌍.pdf`는 사용자가 제공한 원본 PDF를 그대로 복사한 파일입니다. 총 42페이지이며, 각 페이지에 와이어프레임과 기존 목업이 한 쌍씩 있습니다.
- PDF 안의 기존 목업과 최종 PNG의 시각 스타일이 다르면 최종 PNG를 적용합니다. 화면별 기능과 전환은 와이어프레임 및 별도로 전달하는 설계 자료를 함께 확인합니다.
- 이 묶음은 요청한 와이어프레임·에셋·폰트 자료입니다. 최종 화면 42장, 설계도 10종, 중간심사 피드백 문서는 이 ZIP에 중복 수록하지 않았습니다.
- PDF의 기존 외부 링크를 유지했습니다. 연결 대상의 접근 권한이나 현재 동작까지 보장하는 것은 아닙니다.

## 에셋

`02_assets`에는 최종 42화면 제작에 실제 사용한 PNG 7종이 있습니다.

| 경로 | 용도 |
|---|---|
| brand/malitda_logo.png | 원본 로고 및 태그라인 |
| characters/malitda_robot.png | 청록색 로봇 캐릭터 |
| characters/malitda_purple.png | 보라색 캐릭터 |
| meaning_cards/walk.png | 산책하고 싶어요 |
| meaning_cards/water.png | 물이 필요해요 |
| meaning_cards/rest.png | 쉬고 싶어요 |
| meaning_cards/cold.png | 바람이 차가워요 |

에셋은 제공된 PDF 안의 이미지에서 추출하거나 필요한 그림 영역을 잘라낸 파일입니다. 별도로 제공받은 AI·PSD·SVG·3D 모델 원본은 없습니다. 생성형 재작화, 비율 왜곡, 색상 변경, 해상도 확대는 하지 않았습니다.

로고·캐릭터·그림의 가로세로 비율을 유지하고, 캐릭터의 눈·팔·다리와 로고 글자를 다시 그리거나 변형하지 않습니다. PNG 배경과 투명도도 추출된 상태를 유지합니다. 원래 크기와 출처는 `에셋_출처_크기.csv`에 정리했습니다.

일부 그림과 캐릭터는 PDF 속 화면 이미지에서 추출되어 해상도가 낮습니다. 최종 UI PNG가 1206×2622인 것과 개별 에셋이 고해상도인 것은 다릅니다. 별도의 고해상도 원본이 확보되면 동일한 그림인지 확인한 뒤 교체합니다.

## 폰트

- `03_fonts/Jua/Jua-Regular.ttf`: 최종 재디자인의 제목·본문·버튼에 실제 사용한 Jua 폰트입니다. 원래 전달된 모든 디자인에 이 폰트가 사용되었다는 의미는 아닙니다.
- Jua는 이 자료에서 Regular 파일 하나를 사용했습니다. 글자 자체가 두껍고 둥근 형태이며 별도 Bold 파일은 없습니다. 시안의 일부 강조 글자에는 아주 얇은 외곽선이 적용되어 있으므로, 구현 시 과도한 가상 볼드 대신 최종 PNG와 비교해 조정합니다.
- `03_fonts/DejaVu/DejaVuSans-Bold.ttf`: PNG의 9:41 상태 표시줄 숫자에 사용한 보조 폰트입니다. 실제 앱에서 운영체제 상태 표시줄을 사용할 때는 해당 UI를 별도로 그릴 필요가 없습니다.
- Jua에 없는 일부 특수문자는 플랫폼 기본 폰트 등으로 폴백합니다. PDF 렌더링 작업에서 임시로 사용한 폴백 폰트는 이 전달 묶음에 포함하지 않았습니다.
- 각 폰트 폴더에 라이선스 전문을 동봉했습니다. 폰트 재배포 시 해당 고지 파일을 함께 유지합니다.

## 화면 크기와 구현 참고

- 최종 PNG: 1206×2622px.
- 시안 작성 기준: 402×874 논리 좌표를 3배로 출력.
- 실제 앱은 기기의 안전 영역과 운영체제 상태 표시줄·홈 인디케이터에 맞춰 배치합니다. PNG 전체를 배경으로 붙이는 방식이 아니라 텍스트·버튼·카드·그림을 각각 구현합니다.
- `화면_파일_대응표.csv`에서 화면 번호, 화면 ID, 최종 PNG 파일명, 원본 PDF 페이지를 확인할 수 있습니다.
