# 말잇다 0.3.2 디자인 마감 검증

함께 관리의 본문을 끝까지 확인한 결과, 실증 준비·기록이나 CSV·조건 비교로 들어가는 버튼은 보이지 않았다. 일반 표현 등록·미확인 뜻·학생 변경·개인 자료 관리 흐름은 유지됐다. 자료 관리 화면의 이전 시험 기록 영역도 일반 카드 확인 전후 모두 숨겨져 있었다. 이 영역은 기록이 한 건 이상일 때 표시하는 구조이므로 UI와 소스 계약상 0→0으로 관측했다. 암호화 DB의 행을 직접 조회하거나 과거 A조건을 강제 주입한 결과는 아니다.

320·390·430dp에서 글자 크기 100%로 대표 화면 21장을 다시 캡처했다. 이 범위에서 로고·하단 탭·주요 버튼 라벨의 겹침이나 잘림은 발견하지 못했다. 설정 로봇에서 드러나던 흰 모서리를 확인해 수정 요청했고, 최종 이미지에서는 모서리가 정돈된 것을 확인했다. 지원자 설명과 전체 삭제 확인창의 새 문구도 실제 화면에서 확인했다. 삭제 확인은 취소하여 자료를 보존했다.

390dp·100%에서 18초 화면 녹화로 눌림 반응과 탭 전환을 확인했다. 대표 프레임에서 글자가 다시 배치되거나 화면이 크게 흔들리는 현상은 보이지 않았다. OS 애니메이션 설정 세 항목을 0으로 바꿔도 홈과 목록 이동은 동작했으며, 이후 기존 값으로 복원했다. 실제 100/140/650ms 달성이나 FPS, 사용자가 느끼는 자연스러움은 측정하지 않았다. TTS 발화 중 효과의 별도 실측도 이번 범위에는 포함하지 않았다.

최종 APK 대상 계측 48개가 모두 통과했다(exit 0, 전체 실행 8.313초). 이후에도 기존 합성 프로필의 활성 뜻 2개·미확인 뜻 1개와 동의·PIN이 유지됐다. 이 실행 시간은 앱 성능 기준 수치가 아니다. 실물 휴대전화·실제 이용자·실제 발화 정확도·유료 AI·외부 발송 검증으로 확대하지 않는다.

증거 버전은 구분했다. 21장 레이아웃과 관리 전체 스크롤은 `f73d8f6a…cae6b0`에서 확인했다. 이후 문구 두 곳과 설정 로봇 모서리만 수정된 `5a505ec3…0f9903`에서 해당 화면·홈/PIN·일반 카드 경로·모션·OS 애니메이션 끄기와 48개 계측을 확인했다. 화면 목록과 정확한 해시는 JSON에 기재했다.

이전 41개 검사 ID는 `qa-coverage-final-polish032.csv`에 유지했다. 최신 변경을 재확인한 항목, 이전 버전 근거만 남은 항목, 아직 확인하지 못한 항목을 나눴다. 특히 이전 QA032에서 관측한 320dp·200% 홈 마이크 위치와 온보딩 첫 쪽 스크롤은 이번 100% 검수로 해결됐다고 판정하지 않았다.

합성 AVD 시작 때 Android System UI의 응답없음 대화상자가 있었고 Wait 후 복귀했다. 해당 구간은 앱의 정상 동작 근거에서 제외했다. 실제 마이크·유료 생성·외부 발송·원본 자료 초기화는 모두 0회다.

주요 파일: `FINAL-POLISH-032.json`, `qa-coverage-final-polish032.csv`, `latest-all-48-instrumentation-summary.json`, `motion-font100.mp4`, `public-captures-font100/`.

기본 390dp·글자 100%와 OS 애니메이션 설정을 복원한 뒤 소유한 읽기 전용 합성 AVD를 종료했다. 종료 직전 앱 크래시 버퍼는 비어 있었고 마이크 권한은 허용되지 않은 상태였다.
