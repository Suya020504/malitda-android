# 개발자 인계

현재 앱 소스는 167f86f다. 원안 100% 수치·4탭·실제 상황 필터·3단계 안내·지원자 세션 잠금과 일반 실증 도구 분리를 포함한다. 핵심 소스는 V2App, V2Style, V2Motion, LibraryBrowse, OnboardingPolicy다.

일반 debug와 모든 release는 `PILOT_TOOLS_ENABLED=false`다. 이전 trialLogging 설정이 남아 있어도 수집·A/B/C 조건·전역 기록 버튼을 켜지 않는다. 과거 기록은 자동 삭제하지 않으며 0건이면 관련 항목을 숨긴다. 비공개 평가 빌드만 `-PenablePrivatePilotTools=true`로 켤 수 있다. release에는 이 옵션을 전달해도 false다. 전용 진입은 private 빌드에서 `adb shell am start -n kr.voicemate.malitda.debug/kr.voicemate.malitda.MainActivity --es malitda.debug.tool pilot`이며 앱 사용 동의·PIN 경계를 유지한다. 이 비공개 빌드의 실제 실행은 이번 마감 QA 범위 밖이다.

일반 APK에는 공급자 키를 넣지 않는다. 기존 개발용 직접 생성 경로와 R4 연결 코드는 보존했다. 키를 포함하는 비공개 개발 빌드는 별도 명시 옵션이 필요하며 공개 APK로 공유하지 않는다. 실제 유료 생성 품질·지연·삭제/보관 정책은 별도 검증한다.

모션: 공통 버튼·홈 마이크·카드·하단 탭의 눌림은 100ms/0.985배다. 화면 진입은 140ms의 약한 fade이며 이전 화면을 유지하지 않는다. 녹음은 1100ms/1.035배 이내, TTS는 실제 재생 중에만 650ms/0.92~1.08배다. OS 애니메이션 끔을 읽고 복귀 때 갱신한다. 프레임 변환만 적용해 줄바꿈과 터치 영역을 흔들지 않는다.

그림 선택 경합: 생성 중 수동 그림 선택은 genRound를 증가시키고 이전 job 결과 적용을 취소한다. 서버에서 이미 시작한 생성이나 비용까지 취소된다는 의미는 아니다. 사진 선택·저장 중 보류 버튼은 실제 disabled 상태를 사용한다.

기본 빌드에는 SDK36·NDK27.2·CMake3.22.1·JDK17과 whisper.cpp 및 해시가 맞는 모델 자산이 필요하다. `scripts/prepare-models.ps1`과 README의 기존 안내를 따른다. 제출 ARM 빌드는 `-PsubmitAbis=arm`을 사용한다. 기기 검증은 ARM APK, 에뮬레이터 검증은 x86 APK로 나눴다. 이번 인계에 SDK·개인정보·음성 원본·키는 포함하지 않는다.
