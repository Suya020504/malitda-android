## 현장 진행 기준

참여 범위가 확정되지 않았다면 치료사 30분 검토를 기본으로 준비한다. 실제 이용자가 참여하면 본인의 확인·거절 방법을 먼저 살피고, 20~30분의 짧은 과업으로 조정한다. 시간은 제안안이다. 방문 일시·인원·동행자·동의·기록 범위를 센터와 확인한다.

연습과 관찰 과업을 구분하며, 독립 완료·조작 도움·뜻 판단 도움·확인 불가·중단을 따로 남긴다. 기록표에는 실제 결과가 들어 있지 않다.

## 개발팀이 먼저 확인할 것

1. 현장 APK 버전과 가이드 기준을 맞추고, 실제 휴대전화의 마이크 권한·한국어 소리·저장 유지 여부를 확인한다.
2. 등록 때 함께 확인하는 단계와 이번에 전달할 뜻을 확인하는 단계를 구분한다.
3. 앱의 ‘뜻을 확정해 전달’ 값은 ‘맞아요’를 누른 기록이다. 상대의 이해나 외부 전송 성공으로 해석하지 않는다.
4. CSV 내보내기는 모든 학생 이름과 기록된 뜻 문장을 텍스트 공유창으로 보낸다. 빈 관찰 양식과 앱 내보내기 결과는 서로 다르다.
5. Figma의 새 모션과 보완 화면이 APK에 이미 구현됐다고 안내하지 않는다.

## 자료 범위와 검증

공식 APK를 임시 시험 기기에서 실행한 기본 예시 화면 17개를 사용했다. 실제 참여자의 화면·음성·관찰 결과는 포함하지 않았다. PDF 16쪽의 구조와 배치를 확인했고, Markdown의 상대 링크·이미지, 빈 CSV 형식과 복사 무결성을 검사했다.

화면 사용법 확인이 실제 발화 인식률·처리 속도·음성 품질·전송 성공·이용자 효과 검증을 뜻하지 않는다. 이 항목은 현장 기기와 참여 범위를 정한 뒤 별도로 확인한다.

실제 참여 기록이나 식별 가능한 화면을 이 공개 폴더에 추가하지 않는다. 화면·캐릭터·로고는 팀 VOICE MATE 디자인 자산이며 별도 허락 없이 재사용할 수 없다.
