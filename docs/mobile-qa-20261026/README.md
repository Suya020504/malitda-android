평소 표현을 개인 뜻과 연결하고 학생이 확인한 뒤 전달한다. 공유 뒤에는 홈에서 마치거나 뜻을 다시 확인할 수 있다. 등록할 때 ‘확인하고 홈으로’를 선택하면 확인한 뜻을 저장하고 홈으로 간다. 미확인 저장은 사용할 수 있는 뜻으로 확정하지 않는다.

반응형 검수는 대표 가상기기의 폭·확대 조합이며 전체 휴대전화 호환 인증은 아니다. 음성 지연의 최초 구동 조건·실제 휴대전화 검증과 실제 이용자 효과가 남아 있으므로 서비스 전체 출시 완료로 판정하지 않는다.

전달 APK에는 공급자 키가 없다. R4 모의 서버와 실제 유료 생성은 구분한다. 직접 생성은 개발자의 비공개 Debug 빌드에서만 `-PincludeDirectImageKey=true`를 명시하고 기존 로컬 설정의 키를 사용할 수 있다. 이 방식의 키 포함 APK는 공개 배포하지 않는다.

Debug 패키지는 `kr.voicemate.malitda.debug`다. 기존 앱과 서명이 달라 덮어 설치되지 않으면 기존 앱을 지우지 말고 같은 팀 서명으로 빌드해 인계한다. 실제 제출에는 팀 서명과 실기기 검증이 필요하다. [Android 서명·업데이트 안내](https://developer.android.com/studio/publish/app-signing).
