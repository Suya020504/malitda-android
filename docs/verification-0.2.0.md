# 말잇다 0.2.0 검증 기록

2026년 10월 6일 정리. 개인 의미 사전과 등록·확인·전달 흐름을 구현해 검증용 APK로 만들었다. 아래는 개발 검증 결과이며 실제 당사자의 의사소통 개선 결과가 아니다.

## 시험한 범위

| 확인 | 결과 | 근거 |
|---|---|---|
| APK 빌드 | 통과 | JDK 17·SDK 36·NDK 27.2·CMake 3.22, arm64-v8a·armeabi-v7a·x86_64 빌드 |
| 단위 테스트 | 45개 통과, 실패·건너뜀 0 | 기존 후보·정규화·평가 + 의미 승인·응답 검증·늦은 결과 거절 |
| Android 저장소·DB 변경 테스트 | 10개 통과 | 기존 4개 테이블의 값 보존, Room 스키마, 학생 복합 FK, 수정·상태·버전·개수 제한 |
| Android Lint | 오류 0, 경고 35 | API 26 테마 호환과 로컬 SDK 경로 오류 수정. 경고는 라이브러리 최신 버전·기존 자산 등이며 미해결 상태로 기록 |
| 설치·실행 | 통과 | Android 16 / API 36 x86_64 가상 기기, 고정 시험 장치 emulator-5560 |
| APK 권한·서명·압축 | 통과 | 인터넷 권한 없음, Android Debug 서명 검증, ZIP CRC 검사 |

처음 실행한 DB 변경 시험 2개는 Room 시험 도구와 앱의 serialization core/json 버전 차이로 중단됐다. 두 버전을 1.8.1로 맞춘 뒤 10개를 모두 다시 실행해 통과했다. 시험을 끄거나 실패를 숨기지 않았다.

## 실제 화면 조작

실제 UI 트리에서 버튼·입력창의 위치를 확인해 조작하고 화면을 저장했다. `wind → walk please`, `TestStudent`는 개발용 가상 자료다. APK에 이 자료를 기본 데이터로 넣지 않았다.

- 표현·뜻·그림을 미확인으로 저장하고, 미확인 상태의 뜻이 사용 카드에 나타나지 않는 것을 확인했다.
- 확인 방법과 함께 확인했다는 선택이 없으면 사용 버튼이 비활성이다. 두 조건을 선택한 뒤 등록이 활성화됐다.
- 카드로 선택 → ‘맞아요’ → 전달 화면을 확인했다. ‘다른 뜻이에요’는 카드 선택으로 돌아갔다.
- 공유창에 확인한 문장이 표시됐다. 실제 다른 앱으로 보내지 않고 취소했으며 기존 전달 화면이 유지됐다.
- 소리 버튼 요청 후 화면은 유지됐다. 실제 출력 음성을 듣고 평가하지는 않았다.
- 표현을 수정하면 미확인으로 바뀌며 홈에서 숨겨졌다. 사용 중지·다시 사용·삭제·삭제 취소도 확인했다.
- 다른 학생을 추가하면 사전이 비었고, 원래 학생으로 돌아오면 등록한 뜻이 복원됐다.
- 글자 크기 1.6배, 360×640dp 화면에서 스크롤해 선택·확인·전달에 접근했다. 등록 확인 화면의 재생성도 확인했다.
- 앱을 배경으로 보낸 뒤 시험 프로세스가 실제 종료된 것을 확인하고 재실행했다. 이전 전달 승인은 복원되지 않았고 다시 뜻을 고르라는 안내가 표시됐다. 첫 자동 시험은 배경 전환이 끝나기 전에 종료 명령을 보내 프로세스가 남았으므로 완료로 세지 않았다.
- 마이크 권한 요청과 거부를 확인했다. 거부 안내에서 카드 선택으로 이어졌다.
- 사진 선택 중 글자 크기를 변경한 뒤 시험 그림을 선택했다. 앱 전용 파일로 복사되고 등록 화면에 표시되는 것을 확인했다. 원본은 변경하지 않았다.
- 메뉴의 모든 항목에 접근했다. 기존 메뉴가 5개까지만 표시하던 문제는 스크롤 가능한 메뉴로 교체했다.

- 크기: 287,481,627바이트, 약 274MiB. 두 음성인식 모델을 포함한다.
- SHA256: `b9b76e025c1380ae4b9ae1acdfafc71179adee24fab9bccc1c4016546f8de36e`

디버그 서명 APK는 기존 제출 앱과 별도로 설치하는 시험본이다. 기존 제출 앱을 지우거나 기존 데이터가 들어 있는 앱을 이 파일로 덮어쓰지 않는다. 정식 제출용 업데이트는 팀의 기존 서명키로 릴리스 빌드를 해야 한다.

## 아직 확인하지 않은 것

- 실제 휴대전화의 마이크·한국어 TTS·배터리·처리 시간, 실제 당사자 발화의 인식 정확도와 의미 전달 효과
- 팀의 실제 서명키를 사용한 기존 제출 앱의 설치 업데이트
- 초기 대상과 학생별 확인·거절 방법에 대한 현장 검증
- 새 언어모델, Jev, 온라인 API, 유사검색의 효과. 이번 버전은 완전일치 검색과 기본 규칙 순서만 사용한다.
- Figma 42개 상태 전체의 구현·최종 디자인 리터칭. 이번 범위는 핵심 흐름과 관련 예외다.
- 선택한 사진의 자동 정리 정책. 표현 삭제는 DB 기록·별칭·확인 기록을 삭제하며, 사진 파일 정리는 별도 보완 항목이다.
