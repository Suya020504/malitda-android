# 말잇다 모바일·AI 작업 인계

2026년 10월 7일. 앱의 개인 의미 사전·뜻 확인·전달은 실행 가능한 0.2.0-debug에 구현했다. 새 모바일 시안은 다음 디자인 적용 목표이며, 의미 후보용 언어모델은 아직 연결하지 않았다.

기존 피그마도 모바일 프레임이었다. 큰 보드에 묶인 화면을 전용 인계 페이지로 정리하고 좁은 화면의 카드·입력 폭과 연결을 보완했다. 원본 페이지와 자산은 유지했다. 새 시안 48개 전체가 현재 APK에 구현된 것으로 해석하지 않는다.

실행 코드 기준은 `f00b7221b6ccc43a6ae64c9d409b0987309fee1c`다. 이후 이 브랜치의 인계 문서 커밋은 실행 코드를 바꾸지 않았다. 단위 45개·Android 데이터 10개 통과와 Lint 오류 0·경고 35는 그 APK의 기존 검증 결과다. 10월 7일에는 사이트와 APK 화면을 다시 확인하고, 피그마 연결·폭·폰트를 검사했다. 실제 당사자 효과·전체 보조기술·정식 제출 서명은 미검증이다.

- [48개 화면 ID와 현재 코드 경로](handoff/mobile-screen-index-20261007.json)
- [AI 가상 명세 벡터 30개](handoff/ai-contract-vectors-20261007.json): 새 모델에 실행한 결과가 아니다.
- [기존 AI 상세 계약](ai-integration-contract.md), [팀 협업 안내](ai-collaboration-handoff-ko.md)

AI는 입력 후보 전체의 ID 순서만 바꾸거나 판단을 보류한다. 등록·학생 선택·승인·전달은 앱이 맡는다. 디자이너는 확인·거절 방법과 상태를 유지하고, 앱 담당자는 오래된 응답·학생 변경·등록 수정 이후 이전 승인을 적용하지 않는다.

로컬 전달 묶음에는 화면 비교 그림, 실제 앱 캡처, AI 설계도 PDF와 PNG를 넣었다. 원음·실제 개인 사진·은행/서명 서류·키·SDK·모델 파일은 이 PR에 포함하지 않는다.
