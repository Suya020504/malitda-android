# 의미 그림 추가 가이드

학생이 뜻을 고르고 확인할 때 보는 그림(의미 카드)을 늘리는 방법입니다. 그림은 팀이 미리 만들어 앱에 넣습니다. 앱은 그림을 만들기 위해 인터넷에 연결하지 않으며, 학생의 표현이나 뜻이 외부로 전송되지 않습니다.

> **먼저 합의할 것**: 디자이너 전달 문서는 기존 그림을 "생성형으로 다시 그리지 않았다"고 밝히고 있습니다. 새 그림을 AI로 만든다는 사실을 디자이너와 먼저 합의하고, 결과물 검수도 디자이너가 맡는 것을 권합니다.

## 1. 그림 만들기 (GPT 이미지 생성)

### 레퍼런스로 함께 넣을 그림

기존 의미 카드 4장을 모두 첨부합니다. 저장소의 아래 위치에 있습니다.

- `design/v2/handoff/02_assets/meaning_cards/walk.png` 산책하고 싶어요
- `design/v2/handoff/02_assets/meaning_cards/water.png` 물이 필요해요
- `design/v2/handoff/02_assets/meaning_cards/rest.png` 쉬고 싶어요
- `design/v2/handoff/02_assets/meaning_cards/cold.png` 바람이 차가워요

### 프롬프트 (그대로 복사해서 `[뜻]`과 `[장면]`만 바꿉니다)

```
첨부한 4장의 그림과 같은 화풍으로 새 그림을 한 장 그려 주세요.

- 화풍: 부드러운 3D 클레이 느낌, 둥근 형태, 파스텔 색감, 밝고 따뜻한 빛
- 배경: 단순하고 흐릿하게, 주인공이 한눈에 보이도록
- 사람이 나오면 얼굴을 자세히 그리지 말고 뒷모습이나 단순한 형태로
- 글자, 숫자, 로고, 말풍선은 넣지 않기
- 비율: 가로 3 : 세로 2 (1536 × 1024)

전할 뜻: [뜻]   예) 화장실에 가고 싶어요
장면: [장면]   예) 깨끗한 화장실 문과 손 씻는 세면대가 보이는 밝은 복도
```

### 고를 때 확인할 것

- **한눈에 뜻이 보이는가**: 글자 없이 그림만 보고 뜻을 짐작할 수 있어야 합니다. 학생이 글자를 읽지 못해도 고를 수 있게 하는 것이 그림의 역할입니다.
- **기존 4장과 나란히 놓았을 때 어색하지 않은가**: 색감과 질감이 튀면 다시 생성합니다.
- **불안하거나 자극적인 요소가 없는가**: 어두운 장면, 다치는 모습, 무서운 표정은 피합니다.
- **화면 안의 글자**: 그림 속에 글자가 생겼다면 사용하지 않습니다.

## 2. 앱에 넣기

1. 고른 그림을 **1536 × 1024 PNG**로 저장합니다. 파일 이름은 `v2_card_<키>.png`이고, 키는 영어 소문자와 밑줄만 씁니다. 예: `v2_card_toilet.png`
2. 파일을 `app/src/main/res/drawable-nodpi/`에 넣습니다.
3. `app/src/main/java/kr/voicemate/malitda/ui/v2/V2Style.kt`의 `BUILTIN_MEANING_IMAGES`에 한 줄 추가합니다.

   ```kotlin
   "toilet" to R.drawable.v2_card_toilet,
   ```

4. 빌드하면 그림 선택 화면(뜻을 보여줄 그림)에 새 그림이 나타납니다. 5개씩 한 줄로 늘어납니다.

**주의**: 키는 학생의 뜻 데이터에 저장됩니다. 한 번 배포한 키는 이름을 바꾸거나 지우지 마세요. 지우면 그 그림을 쓰던 뜻이 "그림 없음"으로 바뀝니다.

## 3. 먼저 만들면 좋은 그림

반영계획서가 첫 실증에서 관찰하자고 한 "물건 요청·활동 선택·장소·거절" 장면에 맞춘 후보입니다. 위에서부터 우선순위가 높습니다.

| 키 | 전할 뜻 | 장면 예시 |
|---|---|---|
| `toilet` | 화장실에 가고 싶어요 | 밝은 복도의 화장실 문과 세면대 |
| `hungry` | 배고파요 | 따뜻한 밥과 반찬이 놓인 식탁 |
| `hurt` | 아파요 | 반창고와 구급상자, 걱정하는 분위기 없이 차분하게 |
| `stop` | 싫어요, 그만할래요 | 멈춤을 뜻하는 손바닥, 부드러운 색 |
| `help` | 도와주세요 | 손을 내미는 두 손 |
| `home` | 집에 가고 싶어요 | 따뜻한 불빛의 작은 집 |
| `more` | 더 주세요 | 그릇에 음식을 조금 더 담는 모습 |
| `hot` | 더워요 | 햇볕과 선풍기 |
| `sleepy` | 졸려요 | 포근한 베개와 이불 |
| `music` | 음악 듣고 싶어요 | 헤드폰과 음표 모양 장식(글자 없이) |

기존 4장(산책·물·휴식·찬바람)과 겹치지 않게 골랐습니다. 실증 참여자가 실제로 쓰는 표현이 정해지면 그 목록을 우선합니다.

## 4. 그림이 없을 때

그림이 아직 없는 뜻은 지원자가 **사진 가져오기**로 학생에게 익숙한 실제 사진(자주 가는 산책로, 쓰는 컵 등)을 쓸 수 있습니다. 사진은 앱 전용 저장 공간에만 보관됩니다.
