# 실제 테스트 체크리스트 (말잇다 v0.2.5 실증 · 2026-10-26 종료)

현장 실증 전날·당일에 지원자가 순서대로 확인한다. 2026-10-24~25 에뮬레이터 점검 결과를 바탕으로 작성.

## 1. 어떤 APK를 쓸지 먼저 정한다

| 상황 | APK | 비고 |
|---|---|---|
| 그림 만들기 없이 실증(권장) | GitHub 릴리스 **v0.2.5** — 점검 수정과 음성인식 개선이 모두 들어 있다. 이전 버전(0.2.2~0.2.4)은 쓰지 않는다 | 인터넷 권한 없음. 완전 오프라인 |
| 현장에서 지원자가 그림도 만들어야 함 | 디버그 APK + PC의 R4 서버 | USB 연결 + `adb reverse tcp:8769 tcp:8769` 필요. 케이블을 빼면 그림 만들기만 꺼지고 나머지는 정상 |

- 릴리스와 디버그는 **서로 다른 앱**(데이터 공유 안 됨)이다. 실증 전에 등록한 뜻은 실증에 쓸 그 APK에서 등록한다.
- 그림은 전날 디버그로 만들어 두고 당일엔 릴리스로… 는 **불가**(데이터가 옮겨지지 않음). 그림이 필요하면 디버그 하나로 끝까지 간다.

## 운영 주의 (실증 기간 내내)

1. **학생 이름은 별칭으로 등록한다** (예: 학생A, 학생B). 실증 기록 CSV의 `profile` 칸에 앱에 적은 이름이 그대로 들어가서, 팀 드라이브에 올리면 개인정보가 된다. 별칭과 실제 학생의 대응표는 앱 밖에서 따로 관리한다.
2. **등록한 뜻은 그 휴대폰 안에만 있다.** 백업이 꺼져 있고 뜻 내보내기 기능도 없다. 앱 삭제·휴대폰 교체·디버그↔릴리스 바꿔 쓰기 중 하나만 해도 등록한 뜻이 전부 사라진다. → 실증 기간에는 **앱 삭제 금지, 같은 폰 하나로 진행**. 새 버전은 지우지 말고 위에 업데이트 설치한다.
3. **오인식은 준비 단계에서 미리 연결해 둔다.** v0.2.5부터 앱이 학생의 등록 표현을 인식기에 힌트로 주고, 한 글자(자모 하나)만 다르게 들린 말도 후보로 보여 준다(점검 때 바람→아람, 목말라→못말라가 고쳐짐). 그래도 학생 목소리는 녹음과 다르니, 전날 학생 목소리로 2~3번씩 말해 보고 여전히 틀리게 들린 말은 카드로 고쳐 연결해 둔다. 단 '좋아'처럼 평소에도 쓰는 말은 연결하지 않는다(4절 참고).
4. **표현은 학생이 실제로 하는 말 그대로, 여러 개 등록한다.** 등록한 표현이 곧 인식기 힌트가 된다. 학생이 "바람", "바암", "추어"처럼 말한다면 그 소리 그대로 적는 게 정확도에 가장 크게 도움이 된다.

## 2. 전날 준비 (지원자)

- [ ] 실제 쓸 휴대폰에 설치하고 **마이크 권한 허용** 확인
- [ ] 휴대폰 미디어 음량을 키우고 '소리로 확인하기'로 TTS 한국어 음성이 나오는지 확인(음성 데이터가 없으면 설정 › 텍스트 음성 변환에서 한국어 설치)
- [ ] 설정 › 학생 이름을 **별칭**(학생A 등)으로 바꾸기(여러 학생이면 학생 추가) — 운영 주의 1
- [ ] 설정 › **예시 뜻 지우기**: 기본 4종(산책·물·쉬기·바람)을 지운다. 학생 뜻과 섞이지 않게
- [ ] 학생과 함께 자주 쓰는 뜻 등록(U05): 전할 뜻 문장 + 학생이 실제로 하는 말 여러 개 + 그림(사진·기본 그림)
- [ ] 등록한 뜻은 **학생 확인(U10)** 을 마쳐야 홈 카드와 말하기에 나온다. 확인 대기 뜻이 남아 있지 않은지 내 표현에서 확인
- [ ] 휴대폰에서 학생 목소리로 등록한 말을 2~3번씩 말해 보고 연결되는지 확인. 틀리게 들린 말은 미리 연결 — 운영 주의 3
- [ ] 설정 › 글자 크기를 학생에 맞추기
- [ ] 설정 › **실증 기록 켜기** (기본 꺼짐. 켜야 시도 기록이 남는다)

## 4. 앱이 잘못 알아들었을 때

- '이 뜻이 맞나요?'에 다른 뜻이 나오면 학생이 '다른 뜻이에요'를 누른다. v0.2.5부터 한 글자만 비슷한 뜻도 후보로 나오므로, 학생이 확인하기 전에 지원자가 대신 '맞아요'를 누르지 않는다.
- '아직 모르겠어요' 화면의 **들은 말**을 보고, 카드로 맞는 뜻을 고르면 "다음부터 '○○'도 ~로 알아들어요"를 묻는다.
- **평소에 쓰지 않을 말만 연결**한다. 예: '아람'(바람 오인식)은 연결해도 되지만, '좋아'(추워 오인식)는 평소에도 쓰는 말이라 연결하면 진짜 '좋아'까지 '바람이 차가워요'가 된다.
- 잘못 연결했으면 내 표현 › 해당 뜻 › **표현과 뜻 수정**에서 그 말을 지우고 학생과 다시 확인한다.

이번 점검에서 고친 것(v0.2.2 이후):
