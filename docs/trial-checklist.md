# 실제 테스트 체크리스트 (말잇다 v0.2.2)

현장 실증 전날·당일에 지원자가 순서대로 확인한다. 2026-10-24 에뮬레이터 점검 결과를 바탕으로 작성.

## 1. 어떤 APK를 쓸지 먼저 정한다

| 상황 | APK | 비고 |
|---|---|---|
| 그림 만들기 없이 실증(권장) | 릴리스 APK — 2026-10-24 수정 4건이 들어간 **새 릴리스(0.2.3)** 를 쓴다. v0.2.2에는 아래 수정이 없다 | 인터넷 권한 없음. 완전 오프라인 |
| 현장에서 지원자가 그림도 만들어야 함 | 디버그 APK + PC의 R4 서버 | USB 연결 + `adb reverse tcp:8769 tcp:8769` 필요. 케이블을 빼면 그림 만들기만 꺼지고 나머지는 정상 |

- 릴리스와 디버그는 **서로 다른 앱**(데이터 공유 안 됨)이다. 실증 전에 등록한 뜻은 실증에 쓸 그 APK에서 등록한다.
- 그림은 전날 디버그로 만들어 두고 당일엔 릴리스로… 는 **불가**(데이터가 옮겨지지 않음). 그림이 필요하면 디버그 하나로 끝까지 간다.

## 2. 전날 준비 (지원자)

- [ ] 실제 쓸 휴대폰에 설치하고 **마이크 권한 허용** 확인
- [ ] 휴대폰 미디어 음량을 키우고 '소리로 확인하기'로 TTS 한국어 음성이 나오는지 확인(음성 데이터가 없으면 설정 › 텍스트 음성 변환에서 한국어 설치)
- [ ] 설정 › 학생 이름을 실제 학생 이름으로 바꾸기(여러 학생이면 학생 추가)
- [ ] 설정 › **예시 뜻 지우기**: 기본 4종(산책·물·쉬기·바람)을 지운다. 학생 뜻과 섞이지 않게
- [ ] 학생과 함께 자주 쓰는 뜻 등록(U05): 전할 뜻 문장 + 학생이 실제로 하는 말 여러 개 + 그림(사진·기본 그림)
- [ ] 등록한 뜻은 **학생 확인(U10)** 을 마쳐야 홈 카드와 말하기에 나온다. 확인 대기 뜻이 남아 있지 않은지 내 표현에서 확인
- [ ] 휴대폰에서 학생 목소리로 등록한 말을 2~3번씩 말해 보고 연결되는지 확인
- [ ] 설정 › 글자 크기를 학생에 맞추기
- [ ] 설정 › **실증 기록 켜기** (기본 꺼짐. 켜야 시도 기록이 남는다)

## 3. 당일

- [ ] 휴대폰 충전·화면 꺼짐 시간 늘리기(설정 › 디스플레이)
- [ ] 방해 금지 모드(알림이 뜻 화면을 가리지 않게)
- [ ] 처음 '말하기'는 인식 모델을 불러오느라 늦다 — 시작 전에 한 번 말해 두기
- [ ] 시도마다 학생이 '맞아요'를 직접 누르게 하기(지원자가 대신 누르지 않기)

## 4. 앱이 잘못 알아들었을 때

- '아직 모르겠어요' 화면의 **들은 말**을 보고, 카드로 맞는 뜻을 고르면 "다음부터 '○○'도 ~로 알아들어요"를 묻는다.
- **평소에 쓰지 않을 말만 연결**한다. 예: '아람'(바람 오인식)은 연결해도 되지만, '좋아'(추워 오인식)는 평소에도 쓰는 말이라 연결하면 진짜 '좋아'까지 '바람이 차가워요'가 된다.
- 잘못 연결했으면 내 표현 › 해당 뜻 › **표현과 뜻 수정**에서 그 말을 지우고 학생과 다시 확인한다.

## 5. 끝난 뒤

- [ ] 설정 › 실증 기록 › CSV 내보내기 → 팀 공유 폴더에 저장
- [ ] 다음 학생이 쓰기 전에 학생 전환 확인(기록은 학생별로 따로 남는다)

## 에뮬레이터로 확인한 것 / 못 한 것

확인함(2026-10-24): 첫 실행 → 홈 → 카드 선택 → 소리 확인 → 전달 → 공유창 · 취소, 녹음 음성 8개 말하기 흐름(등록된 말 3개 정상 연결·미등록 말 2개는 올바르게 '모르겠어요'·Whisper 오인식 3개: 바람→아람, 목말라→못말라, 추워→좋아), 오인식 학습(연결 뒤 같은 녹음이 바로 맞음), 등록·중복 경고·수정·학생 확인·미확인 보관함·사용 중지·삭제, 학생 추가·전환·이름 변경, 실증 기록 요약·CSV, 글자 크게, 도움 창, 예시 뜻 지우기, 그림체 선택·그림 만들기(가짜 생성기 서버)·서버 꺼짐 안내, 앱 재시작 후 데이터 유지, 자동 테스트(단위 35 · 기기 8), 릴리스 빌드에 인터넷 권한·서버 주소 없음.

이번 점검에서 고친 것(v0.2.2 이후):
1. 내 표현에서 뜻을 고치고 학생 확인을 마치면 전달 화면 대신 그 뜻 상세로 돌아간다(실증 기록에 가짜 시도가 섞이지 않게)
2. 미확인 보관함에서 뜻을 누르면 상세가 열려 수정·삭제할 수 있다(전에는 잘못 저장한 뜻을 지울 방법이 없었음)
3. 실증 기록을 켜면 전달 화면 그림을 낮춰 '지원자가 도와줬어요'가 버튼에 가리지 않게 했다
4. 일부러 그림 없이 등록한 뜻에 "그림을 불러올 수 없어요"가 뜨지 않게 했다
(+ 예시 뜻 지우기 문구를 실제 동작에 맞게 수정)
