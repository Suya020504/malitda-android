# 말잇다 전체 모바일·시스템 설계 인계

2026년 10월 7일. 개인 의미 사전의 실행 코드 f00b722를 기준으로 구조와 누락 상태를 대조했다. 새 그림은 디자인 목표이며 실행 코드를 변경한 것은 아니다.

기존 42개 상태와 대표360폭6개에 안내·설정·처리/저장/불러오기·사용 중지/재사용·기기 기능 참고 30개를 더했다. 78은 독립 기능 개수가 아니다. 기존 원안·42개 와이어/목업·이전48인계 페이지는 보존하며 위 페이지를 최신 인계 기준으로 사용한다.

실제 호스트의 36개 view분기, 전역 모달10개, 상세 모달3개를 [설계 대응표](handoff/runtime-design-coverage-20261007.json)와 [78개 화면표](handoff/complete-screen-index-20261007.json)에 연결했다. 기존 음성 도구는 실제 접근 경로가 있으므로 원안 참고 링크로 보존했다. S21은 독립 route가 없고 S25/S26은 호스트 내 진입 전환이 없는 참고 view다.

코드 대조로 확인한 경계:

- 음성 의미 검색에는 STT 원문과 기존 ui.candidates가 들어가므로 M1 승인 교정 후보가 포함될 수 있다. MeaningViewModel이 별칭 조회·선택을 맡고 Repository는 저장·정규화를 제공한다. 의미 선택을 corrections에 자동 기록하지 않는다.
- 카드는 meaningId 직접 선택·CONFIRMED 재조회 후 뜻 확인이며 별칭 검색·Ranker를 거치지 않는다. 음성 후보2개 이상만1500ms 안에 재정렬·검증한 다음 화면에 제시한다.
- DB6테이블 중 새 의미/별칭2개에는 실제 FK, 기존 표현/교정/집계에는 profileId 논리 관계만 있다. SQLCipher DB와 사진/DataStore의 저장 방식은 다르다.
- 등록 확인은 확인 방법 기록+체크가 필요하고 지원자 이름은 선택이다. 이번 전달 승인은 비영속이며 변경/취소/학생 전환 후 해제한다.
- TTS 미리 듣기와 승인 후 전달을 구분한다. OS TTS·공유는 앱 밖 경계이며 공유창 열림/닫힘으로 실제 전송 성공을 확정하지 않는다.
- 전체 자료 삭제·문의·사진 GC는 미완료다. 새 의미 모델·서버 계정·클라우드 학습을 현재 구현에 추가하지 않았다.

디자이너는 핵심6흐름, 공통 스타일, 조건·오류·복귀·키보드·큰 글자·긴 문구를 마감해 화면ID와 동작 변경을 앱 담당에게 넘긴다. AI 담당은 별도 어댑터와 같은 조건의 결과를 앱 담당에게 넘긴다. 실제 기기·당사자 효과·전체 접근성·정식 서명 검증은 별도 후속 작업이다.
